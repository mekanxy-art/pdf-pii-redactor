# Mitwirken

Danke für dein Interesse! So startest du:

1. Repository forken und klonen.
2. Umgebung anlegen und Abhängigkeiten installieren (siehe README, Schnellstart).
3. Einen Branch erstellen: `git checkout -b feature/mein-feature`.
4. Änderung umsetzen und **Tests ergänzen**.
5. `python -m pytest` ausführen. Alle Tests müssen grün sein.
6. Pull Request mit kurzer Beschreibung öffnen.

## Regeln
- Keine echten Dokumente oder personenbezogenen Daten in Tests, Issues oder Pull Requests.
- Neue Erkennungsregeln brauchen einen Validator (Prüfsumme oder Plausibilitätsprüfung) und Tests für gültige und ungültige Werte.
- Kleine, fokussierte Änderungen; Commit-Nachrichten im Imperativ (z. B. „Add Luhn check").
