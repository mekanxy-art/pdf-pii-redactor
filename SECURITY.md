# Sicherheit und Datenschutz

## Meldung von Schwachstellen
Bitte melde Sicherheitsprobleme über **GitHub: Security → Report a vulnerability** (Private vulnerability reporting) und nicht als öffentliches Issue.

## Wichtig bei Fehlermeldungen
Poste in Issues, Pull Requests oder Logs **keine echten Dokumente und keine personenbezogenen Daten**. Nutze erfundene Beispiele (z. B. mit `make_test.py`).

## Grundsätze des Projekts
- Dokumentverarbeitung ausschließlich lokal; Internet wird für die erste Installation von Paketen und Modell benötigt
- JSON-Reports enthalten nur Typ und Anzahl der Treffer. Die lokale Nachprüfung zeigt mögliche Resttreffer als Klartext; solche Ausgaben nicht öffentlich teilen.
- Das Tool bietet keine Garantie für vollständige Erkennung; Ergebnisse sind zu prüfen
